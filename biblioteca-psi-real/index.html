Como funciona

Simples de usar,
fácil de contribuir

01
Acesse qualquer material
Cada material é uma página HTML independente — funciona no celular, tablet e computador, sem login ou instalação.
02
Use na supervisão
Abra durante a sessão de supervisão, navegue pelo índice interativo e use as seções como roteiro de discussão clínica.
03
Contribua com novos materiais
Crie um fork no GitHub, adicione seu material em HTML seguindo o template e abra um Pull Request. Toda contribuição é bem-vinda.
04
Acesso gratuito para sempre
Open source e publicado via GitHub Pages. Nenhuma barreira de acesso — para supervisoras, estagiários e pesquisadores.

Tem um material para contribuir?

A biblioteca cresce com a comunidade. Se você tem um material estruturado sobre TCC que gostaria de compartilhar, abre um PR no GitHub.
