# 📚 Biblioteca Psi Real

Recursos clínicos estruturados e visualmente cuidados para supervisoras e terapeutas em **Terapia Cognitivo-Comportamental (TCC)**. Acesso gratuito e aberto para toda a comunidade.

🔗 **[Acessar a Biblioteca](https://SEU_USUARIO.github.io/biblioteca-psi-real)**

---

## ✨ O que é

A Biblioteca Psi Real é uma coleção de materiais clínicos em TCC — formulações, técnicas, avaliações, protocolos — apresentados de forma visualmente cuidada, navegável e pronta para usar em supervisão ou estudo.

Cada material é uma página HTML independente, sem necessidade de login, instalação ou assinatura.

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório público no GitHub chamado `biblioteca-psi-real`
2. Faça upload de todos os arquivos
3. Vá em **Settings → Pages**
4. Em **Source**, selecione `main` e pasta `/ (root)`
5. Clique em **Save**
6. Em alguns minutos o site estará em: `https://SEU_USUARIO.github.io/biblioteca-psi-real`

---

## 🤝 Como contribuir

Contribuições são bem-vindas! Para adicionar um novo material:

1. Faça um **fork** do repositório
2. Crie uma pasta em `materiais/nome-do-material/`
3. Crie seu `index.html` seguindo o estilo dos materiais existentes
4. Adicione o card na página principal (`index.html`)
5. Abra um **Pull Request** com uma breve descrição do material

**Diretrizes para materiais:**
- Conteúdo baseado em referências bibliográficas clínicas
- HTML único e autocontido (sem dependências externas complexas)
- Responsivo (funciona em celular e computador)
- Índice navegável para materiais com várias seções
